# Case study 2: Windows search + Copilot (outline)

**Working title:** Testing our way to a Copilot-powered Windows search

**Status:** NDA. Likely unreleased: show it only in a password-protected page or an interview deck, after your manager clears it.

**Role:** product designer, Windows search box experience · Microsoft, 2025

## Evidence in Drive

| Study | When | What it tested | Result |
|---|---|---|---|
| Side-by-side Test 5, "Travel" | Mar 19, 2025 | 4 layouts (A–D) of web results under a local file match | 600 judgments, 212 raters. Concept D won 54% of its matchups, B 49%, A 36%, C 23% |
| Side-by-side Test 6, "Tiger" | Mar 19, 2025 | Same 4 layouts on an ambiguous query | 420 judgments, 149 raters. D 53%, B 43%, C 39%, A 35% |
| Side-by-side Test 10, "Travel" + Edge | Mar 26, 2025 | Same, plus "where do you expect this result to open?" | 360 judgments, 105 raters. B 57%, C 49%, D 39%, A 37% |
| Moderated usability study, "Overall findings" | Nov 2025 | Design A (single column, visual, "phone-like") vs Design B (two columns with a preview pane), with Copilot in search | Participants preferred A's layout; B's settings result and inline toggles won; the preview pane was too small for long Copilot answers; Copilot was welcome if it stays out of the way |
| AI Studio prototype "Windows 11 Search Experience" | Nov 2025 | Working recreation of Windows search with AI content previews | A possible live demo |

Win share = wins ÷ appearances, with neutral votes counted as non-wins. Tests 1–4 and 7–9 aren't in Drive.
